# ستوديو الخيام — إصدار v48

**الإصدار:** v48 LUXURY POLISH  
**التاريخ:** 2026-08-28

هذه الحزمة هي نسخة الموقع الكاملة الجاهزة للرفع. الملفات الأساسية موجودة مباشرة داخل مجلد الإصدار، ولا توجد ملفات ZIP داخلية أو أجزاء منفصلة.

## طريقة الرفع
1. فك ضغط ملف v48 مرة واحدة.
2. افتح مجلد الإصدار الناتج.
3. ارفع جميع محتوياته إلى جذر النشر مع استبدال ملفات الإصدار السابق.
4. تأكد بعد النشر من فتح الصفحة الرئيسية، صفحات الفروع، صفحات الخدمات، النسخة الإنجليزية و`sitemap.xml`.

## بنية الموقع
- `index.html`: الصفحة الرئيسية العربية.
- `en/`: النسخة الإنجليزية.
- `kh1/` إلى `kh10/`: صفحات الفروع الثمانية المعتمدة.
- `services/`: صفحات الخدمات العربية.
- `en/services/`: صفحات الخدمات الإنجليزية.
- `faq/`, `contact/`, `privacy/`, `terms/`: الصفحات المساندة.
- `assets/`: التصميم والبرمجيات والصور.
- `sitemap.xml`, `robots.txt`: ملفات محركات البحث.

## ملاحظات النشر
- لا تُنشر هذه النسخة إلا بعد الاعتماد.
- بعد النشر يجرى فحص الجوال والكمبيوتر والعربية والإنجليزية والروابط وGoogle Maps وWhatsApp.
- بيانات الفروع المستخدمة هي البيانات المعتمدة للمشروع.
