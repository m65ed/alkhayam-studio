# Al Khayam Studio Website Deluxe

ملفات الموقع الجاهزة للرفع على GitHub.

- index.html
- styles.css

- assets/logo.png
- assets/hero-1.png
- assets/hero-2.png
- assets/hero-3.png
- assets/hero-4.png

## طريقة الرفع السريعة
1. افتح مستودع GitHub.
2. اختر **Upload files**.
3. ارفع كل الملفات والمجلد `assets`.
4. اضغط **Commit changes**.
5. بعد الرفع فعّل **GitHub Pages** من Settings > Pages.
